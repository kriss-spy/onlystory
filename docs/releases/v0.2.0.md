# Onlystory 0.2.0

Read Blue Archive, Project SEKAI and Girls' Frontline 1 & 2 stories in one desktop app, with original artwork, audio, choices, bookmarks and offline reading.

## Downloads

- **Windows x64 portable:** run `Onlystory-0.2.0-portable-x64.exe`.
- **Windows x64 installer:** run `Onlystory-0.2.0-Setup-x64.exe`.
- **Linux x64:** extract `Onlystory-0.2.0-linux-x64.tar.gz`, then run `./onlystory-desktop` inside the extracted directory as your normal desktop user.
- Check downloaded files against `Onlystory-0.2.0-SHA256SUMS.txt`.

The desktop app includes its runtime, catalog covers and school/group labels. Story media is downloaded or imported separately. No Node.js installation is needed to run the app.

## Start reading

Open a game, find a story and download it. Blue Archive and Project SEKAI have built-in desktop acquisition. Girls' Frontline 1 & 2 currently require a separately prepared local library. Downloaded stories and reading progress stay on your device.

Blue Archive's getting-started guide explains JP/global coverage, dialogue languages and spoilers. App menus support English, Chinese and Japanese independently of the story language.

## Changes since the preview

- Bundled game/event covers and school/group labels display offline in desktop builds.
- Download history has its own compact page, with expandable event groups, story progress and cancellation. It stays accessible while selecting more stories.
- Downloaded and read counts have explicit labels. Download sizes and file counts retain their spaces.
- Project SEKAI downloads no longer depend on a changing model-discovery index. Original story and asset integrity checks remain enforced.
- Choice text follows the dialogue-size setting.
- C, J and E select available Chinese, Japanese and English story text. Ctrl+C opens Chapters when no text is selected, Ctrl+H opens History, Ctrl+S opens checkpoints, and Ctrl+, opens reader settings.
- F11 expands the reader within the app window. Hide UI affects the reader scene. History also offers unread and alternate text.
- Verified Blue Archive main-story transitions show a notice when gameplay has been omitted.

## Known limits

- Windows executables are unsigned. Linux needs a graphical desktop and Electron's system libraries.
- Language and voice coverage vary by story and the pinned source snapshot.
- Some native Unity cutscenes remain unavailable, with explicit notices. Browser effects approximate the original games.
- Battle notices currently cover verified Blue Archive main-story front/back boundaries. Broader coverage remains tracked in [issue #10](https://github.com/kriss-spy/onlystory/issues/10).
- Active downloads run while their initiating app window is open. History retains the latest attempt for each story.
