## Added

- Shared catalog sidebar and searchable, localized chapter navigation.
- Number shortcuts for choices, automatic first-response selection and special-scene previews.
- Replayable scene, CG and movie markers.
- Clearer download queues and setup guidance.
- CI checks for pushes and pull requests to main.

- Updated Electron to 44.9.3, including the fix for [CVE-2026-115570](https://github.com/electron/electron/security/advisories/GHSA-jr5w-w6x2-84p9), which blocks compromised eMudhra intermediate certificates.
- Updated fast-uri to 3.1.9 to address URI parsing advisories.
- Pinned Pillow 13.0.0 for the development asset scripts, including its security fixes.
- Chinese and Japanese IME search input and rewinding immediately after a choice.
- Blue Archive camera framing, player names and scene loading.
- Remote library access, movie Skip button overlap and Escape closing dialogs.
