# Onlystory 0.3.0

This release improves browsing, reader controls and Blue Archive scene playback.
The experimental Blue Archive reading-route and chronology pages are excluded.
They remain on `codex/issue-20-reading-routes-wip` for further development.

## Downloads

- Windows x64 portable: `Onlystory-0.3.0-portable-x64.exe`.
- Windows x64 installer: `Onlystory-0.3.0-Setup-x64.exe`.
- Linux x64: `Onlystory-0.3.0-linux-x64.tar.gz`.
- Browser app: `Onlystory-web.zip`, served with the included local runner.
- Compare downloads against `Onlystory-0.3.0-SHA256SUMS.txt`.

Desktop builds include their runtime. Story media is acquired separately.
Blue Archive and Project SEKAI support acquisition in the desktop app.
Girls' Frontline 1 and 2 require a separately prepared library host.

## Changes since 0.2.0

- Catalogs and story lists share a sidebar layout. Narrow screens keep search
  and results available while collection details collapse.
- Chapter navigation supports localized titles and search. App language stays
  independent of dialogue language, including playback controls and diagnostics.
- Search preserves Chinese and Japanese IME composition.
- Number shortcuts select reader choices with guards against accidental input.
  Auto reading can select the first response, and locked special scenes can be
  previewed before choosing a route.
- Rewinding immediately after a choice returns to that choice so another
  response can be selected.
- Reader progress includes replayable scene markers, grouped CG sequences and
  distinct movie markers. Movie Skip buttons remain clear of the progress rail.
- Blue Archive restores camera framing after authored pans and uses the
  configured player name in scene text.
- Remote library access and Blue Archive scene loading are fixed.
- Download queues, status labels and getting-started guidance are clearer.
- Dialogs close with the first Escape keypress after opening.

## Known limits and verification

Windows executables are unsigned. Linux requires a graphical desktop and
Electron's system libraries. Building a Linux archive on Windows does not verify
Linux runtime behavior.

Language, voice and source availability vary by story. Some native Unity
cutscenes remain unavailable with explicit notices. Active downloads run while
their initiating app window stays open.

The Blue Archive reading-route experiment, EX import work and full community
chronology are not part of this release. Existing collection browsing and
collection-owned playback order remain available.

See `release/artifacts-current.json` for the exact build commit, artifact sizes,
SHA-256 checksums and checks performed for these files. Historical verification
records do not certify a different build. The source preparation does not publish
or tag a release.
