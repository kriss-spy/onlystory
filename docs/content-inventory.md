- Movies are not imported for GFL1. Browser transitions, framing, actor scaling and some effects approximate native behavior.
- Chapter 14 is not available in the installed replay registry or scripts. Coverage is the selected native replay/event/collaboration inventory, not every script in the archive.
- One source scene is unavailable: Maze Guess, Initial Inference · round, script -59-EXT-AR1.
- Current missing optional source media: TEAPARTYNIGHT, LAKE, 2022saros_Sky, BGM_Pause, BGM_UnPause, SpecialActivity, bossbattle_loop, m_va_spirit_potion, AVG_2023Slow_Heart_telescreen3, AVG_20Winter_Error, AVG_20Winter_Open_Light, AVG_Division_Camera, AVG_Division_Flare_Gun, AVG_The_Division_Grenade_Explosion. - Scenes without confirmed replay placement, alternate endings and gameplay-triggered dialogue remain separately labeled, not inserted into an invented narrative timeline.
- Native rolling credits and some native visual effects have explicit reader notices. Valhalla uses drink outcome choices instead of ingredient mixing.

- 静默突触·终篇 remains absent from the generated import, although its recorded planned opening date is 2026-10-20. This inventory does not query the live game server.
- This is the complete current Onlystory GFL2 imported event catalog, not every GFL2 main story, character archive, or live-game event.
