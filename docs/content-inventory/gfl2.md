## Coverage limits

- No English or Japanese dialogue translation is imported. The en-shaped renderer text object aliases Chinese and is not English support.
- Japanese and Chinese voice choices apply to recovered movies only. Korean exists in some original USM sources but is not selectable/exported.
- Clean portable/installer/web artifacts exclude private library payloads. The local development library has these prepared stories; new clean installations have zero GFL2 online acquisition recipes.
- Source/reconstruction gaps are retained explicitly per chapter, including missing text references; available means readable with the recovered material, not complete original-game fidelity.
- The original 异乡乐徽 and 方糖特调沙龙 editions are not separate imports; their explicitly labeled revised editions are present.
- 静默突触·终篇 remains absent from the generated import, although its recorded planned opening date is 2026-10-20. This inventory does not query the live game server.
- This is the complete current Onlystory GFL2 imported event catalog, not every GFL2 main story, character archive, or live-game event.
