## Secondary cross-checks and limits

The [IOP Wiki event index](https://iopwiki.com/wiki/GFL2_Events) independently lists the CN sequence through 静默突触 and distinguishes main story, character, and minor events. It identifies 于灰败的羽翼中 and 苦涩荆棘与矢车菊 as later campaign names, and marks the August 2025 循迹追演 run as a rerun. This is a secondary cross-check; the primary announcements above take precedence. Its times are in UTC and need conversion before comparison with Chinese notices.

The [4399 official-announcement category's 循迹追演 notice](https://bbs.4399.cn/thread-view-tid-44253972), posted 2024-03-25, gives March 26 as the opening date. This corroborates the original event start and shows why local activity-table timestamps should not be treated as verified release dates. The original [official Weibo reference](https://weibo.com/7367502517/O6EVLxXxB) was discoverable through the index but direct retrieval was blocked.

The generated local catalog supplies the 36 distinct configured event names. Web checks corroborate naming and resolve specific version and release-status issues; this note has not independently verified debut dates for all 36. Current archive tables also do not prove that each original version remains installed or recoverable.
